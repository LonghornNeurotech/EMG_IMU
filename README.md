## Description
This project focuses on IMU based gesture recognition. This is a stepping stone project for the final EMG based Gesture Recognition wearable that provides the Electrical team with an opportunity to work on skills such as soldering, reading component datasheets, and interfacing different components. This project provides the Software team with an almost identical software development pipeline as the final EMG-based device. The team has to collect data from 6 different gesture classes across various session, load the data into a session, visualize data, perform relevant signal processing and data cleaning, train ML models, validate models, and profile performance (including accuracy, energy consumption estimates, latency, jitter, and memory use). Finally, but perhaps most importantly, it tests electrical-software integration by forcing the teams to communicate and work together to complete project deliverables.
