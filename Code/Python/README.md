# Python Software

The Raspberry Pi IMU gesture-recognition project is located in
[`imu_gesture_recognition`](./imu_gesture_recognition/).

The project contains:

- IMU data-collection and synchronization tools
- The P002-P006 100 Hz gesture dataset
- Dataset quality-control tools and reports
- Machine-learning and signal-processing code
- Raspberry Pi acquisition and display code
- Web-application work
- Project documentation and tests

Run project-specific setup and execution commands from the
`imu_gesture_recognition` directory. Its Python dependencies are managed by
`pyproject.toml` and `uv.lock`.
